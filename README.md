# Holdfast website

A framework-free static website for Holdfast. It is intentionally built with plain HTML, CSS, JavaScript, and local image assets so Vercel can deploy it without a build command, output directory, rewrite rule, or package installation.

## Pages

- `/` — home
- `/services/` — member service catalog
- `/network/` — partner-network model
- `/story/` — founding vision and principles
- `/portal/` — interactive owner / partner portal preview

## Deployment

Import this repository into Vercel and select **Other** as the framework. Leave the build command and output directory blank. Vercel serves the project root as a static site.

## Important prototype notes

The portal, chat, member scenarios, company names, service examples, and prospective provider categories are intentionally labeled as illustrative. They should be replaced with actual program terms, contracted provider information, and working integrations as Holdfast launches.
